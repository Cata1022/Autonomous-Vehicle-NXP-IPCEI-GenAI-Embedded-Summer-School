6. Hardware Block Diagram Description

The NXP FRDM-MCXA153 serves as the central hub. It receives power from a step-down 3.3V/5V regulator connected to a 2S LiPo battery. The battery also directly supplies the VCC input of the L298N Motor Driver.

The NXP MCU drives the L298N using two PWM signals for speed (ENA, ENB) and four GPIOs for direction (IN1-IN4). An Ultrasonic Sensor (HC-SR04) connects to the NXP via GPIO (Trigger) and GPIO/Timer (Echo). Note: If the HC-SR04 is 5V, a voltage divider is needed on the Echo pin before it reaches the 3.3V NXP input.

The ESP32-S3 CAM acts as an external peripheral. It communicates with the NXP solely via a 3.3V UART (TX/RX cross-connected). Both boards must share a common ground.

8. Firmware Architecture

Architecture Style: Bare-metal superloop with interrupt-driven UART.

  • Main Loop: Continuously triggers the ultrasonic sensor, measures the echo time to calculate distance, and updates the motor PWM duties. If the distance is below the safety threshold, it immediately forces PWM to zero.
  • Interrupts (UART): The NXP listens to UART RX via interrupts. When a complete packet (e.g., speed and steering vector) is received from the ESP32, it updates global target variables.
  • Motor Mixer Module: A dedicated function translates the target steering vector into independent left/right PWM values for differential steering, applying them only if the obstacle flag is clear.
